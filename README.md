# 🎈 Interactive Bubble Game

A dynamic, web-based interactive game built using **Vanilla JavaScript, HTML5, and CSS3**. Test your reflexes by popping matching target numbers before the timer runs out!

🚀 **[Live Demo](https://bubble-game-by-vishesh-gupta.netlify.app/)** | 📂 **[Source Code](https://github.com/Vishesh-03-hub/Bubble_Game.git)**

---

## 🎯 Features

* **Dynamic Gameplay:** Real-time generation of target numbers and bubble grids using dynamic DOM manipulation.
* **Score & High Score Tracking:** Automatic score updating for each correct bubble hit.
* **Timer Logic:** Interactive countdown timer implemented with JavaScript `setInterval`.
* **Responsive Design:** Styled with modern CSS for optimal layout on both desktop and mobile screens.
* **Clean & Lightweight:** Zero external libraries or heavy dependencies—built entirely with pure web technologies.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3
* **Logic & Interactivity:** JavaScript (ES6+)
* **Hosting/Deployment:** Netlify / GitHub Pages
